# ArizonaSoftwareEngineering
## Part 1: Login

Here at Arizona SWE, we will be creating a platform called InCollege; a platform for college students to connect with other students. Built with the idea that everyone
is looking for a first job and gives tools for them to be successful.

For the first week, we will implement the foundation for InCollege by implementing the core user authentication system. This includes registration + login functionality and 
initial navigation for the alpha. For just the first week, all input will be read from a file rather than user input. All output will be displayed on a screen
